# Тренажер множення — версія 2

Без збирання й без фреймворків: звичайні HTML + CSS + JS-модулі. Працює на GitHub Pages як є.

## Структура

```
index.html            розмітка всіх екранів і вікон (<dialog>)
css/style.css         увесь дизайн (замість Tailwind із CDN)
js/config.js          уроки, рівні, правила, адреса Google Script — ВСЕ, що можна налаштувати
js/engine.js          ігрова логіка без DOM (черга, бали, життя, результат)
js/app.js             екрани, кнопки, клавіатура, таймер
js/storage.js         localStorage (ті самі ключі, що в старій версії)
js/cloud.js           синхронізація з Google Таблицею (фоном, з тайм-аутом)
js/hints.js           текстові підказки + вибір картинки-історії
js/confetti.js        конфеті без сторонньої бібліотеки
assets/tiles.webp     картинки-асоціації (сітка 9×9), 200 КБ замість 2,8 МБ
assets/zero.webp      сонечко для нуля
assets/story/*.webp   картинки-історії, кожна окремим файлом ~12 КБ
tests/engine.test.mjs тести логіки: node tests/engine.test.mjs
```

## Як опублікувати

Скопіюйте вміст папки в репозиторій `math-trainer` (замість старого `index.html`) і зробіть commit. Відкривати локально треба через сервер (`python3 -m http.server`), бо JS-модулі не працюють з `file://`.

## Правила рівнів

| Рівень | Приклади | Помилка | Підказки | Пройдено, якщо |
|---|---|---|---|---|
| Асоціації | усі приклади уроку | підказка + ще спроба; приклад повертається пізніше | текст | дійшли до кінця |
| Тренування | усі приклади уроку | так само | текст, історія, картинки | дійшли до кінця |
| Перевірка | усі приклади уроку | −1 життя, показ відповіді | немає | лишилось хоча б 1 життя з 3 |
| Марафон | без кінця | −1 життя (кінець після 3-ї помилки) | немає | є хоча б 1 бал |

Бали: +1 за правильну відповідь з першої спроби без підказок, −1 за помилку (один раз на приклад, не нижче 0).
Усе це змінюється в `js/config.js` (`MODES`, `SCORING`).

## Google Таблиця (два листи)

Код сервера — у `google-apps-script/Code.gs`.
- **Учні** — один рядок на учня: ID, ім'я, режим вводу, прогрес, дата реєстрації, остання активність, кількість ігор, сума найкращих балів, рекорди (JSON). Рядок з'являється одразу після реєстрації.
- **Статистика** — журнал: рядок на кожну гру (колонки ті самі, що були).

Учні зі старої версії переносяться в «Учні» автоматично, коли вперше входять за своїм ID.

Як оновити: відкрийте таблицю → Розширення → Apps Script → замініть код → **Розгорнути → Керування розгортаннями → ✏️ → Версія: Нова версія → Розгорнути**. URL не зміниться.

## Нові картинки-історії

Зараз є для ×2, ×3, ×4 (і 0/1). Щоб додати, наприклад, ×5: покладіть файли `assets/story/5x2.webp … 5x9.webp` і допишіть `5` у `ASSETS.storyFactors` у `config.js`.
