# Курси

Увесь вміст гри лежить тут, окремо від логіки (`js/`). Один курс — одна папка з файлом `course.json`.

```
courses/
  multiplication/course.json   ← основний курс (таблиця множення)
  <новий-курс>/course.json
```

Відкрити інший курс: `https://romenska.github.io/math-trainer/?course=<назва папки>`.
Вибір запам'ятовується на пристрої; `?course=multiplication` повертає основний курс.
Прогрес і налаштування кожного курсу зберігаються окремо.

## Що є в course.json

| Розділ | Що там |
|---|---|
| `title`, `description`, `texts` | назва гри, підписи на екранах, тексти диплома й сертифіката |
| `backend` | адреса Google Apps Script (своя таблиця для курсу) і репозиторій GitHub |
| `lessons` | уроки: назва, `factors`, місцевість на карті (`place`: назва, тема заглушки, вхід/вихід, точки тренувань `spots`) |
| `modes` | тренування: назва, значок, текст правил і всі налаштування (підказки, життя, темп, ліміт часу, прохідний бал) |
| `map` | розмір картинки уроку (`panel`, вертикальна 1000×1500, уроки зліва направо) і шлях до картинок `lesson{id}.webp` |
| `heroes` | персонажі-аватарки: шлях до картинок, імена, аватарка за замовчуванням |
| `assets` | шляхи до картинок-асоціацій, історій, відео, аудіо і списки наявних файлів |
| `stories`, `hints`, `zeroOneHint` | історії (назва, текст, озвучка, підказка, питання) і текстові підказки |

## Новий курс

1. Скопіюйте папку `multiplication` під новою назвою.
2. Замініть у `course.json` тексти, уроки, історії, персонажів і шляхи до картинок (картинки можна класти в свою папку, напр. `courses/<назва>/assets/…` — шляхи вказуються від кореня сайту).
3. Відкрийте сайт з `?course=<назва>`.

## Дії

`"operation"` у course.json: `mul` (множення), `add` (додавання), `sub` (віднімання), `div` (ділення).
Готові курси: `multiplication`, `addition`, `subtraction`, `division`; перемикач «Курс» — у ручному режимі
(список — `courses/index.json`).

Для додавання, віднімання й ділення поки є лише тренування з числами (Тренування, Перевірка, Марафон,
Повторення, Екзамен). Рівні з картинками-асоціаціями та історіями (Вгадай число, Історії, Асоціації,
Запам'ятай, Пригадай) зав'язані на таблицю картинок 9×9 — для інших дій їм потрібен свій набір картинок.

Обмеження: зовсім інший предмет (слова, літери) потребує нового генератора завдань у `js/ops.js`.
